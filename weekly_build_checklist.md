# Project AURA weekly build checklist

- [ ] Confirm the computer and operating system.
- [ ] Install Python or use Google Colab.
- [ ] Run the dashboard using synthetic data first.
- [ ] Find a legitimate historical data source and check its terms.
- [ ] Upload a CSV and inspect the date and price columns.
- [ ] Test several assets and time periods.
- [ ] Record every strategy change.
- [ ] Compare with a passive benchmark.
- [ ] Include realistic costs and drawdowns.
- [ ] Keep all trades simulated.
- [ ] Research one digital product category before spending money.
- [ ] Validate demand before opening paid listings.
